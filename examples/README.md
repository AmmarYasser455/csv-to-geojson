# Examples

`cities.csv` lists eight world cities with approximate city-centre coordinates
(WGS 84, decimal degrees, rounded to 4 decimals, roughly 10 m).

**Source and license:** the coordinates are public geographic facts, as published
for each city in Wikipedia/Wikidata (coordinate location; Wikidata is CC0). They are
approximate city-centre points, not survey data. No third-party file was copied.

`demo.ipynb` walks through the Python API on this file.
